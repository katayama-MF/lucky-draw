# Chromebook ローカル運用マニュアル（1台運用）

本番イベントで Chromebook 1台で lucky-draw を起動して利用する手順です。  
**Linux 直下に lucky-draw フォルダごとコピー**し、画像・音源もすべてそのフォルダから読み込みます。

---

## 1. 事前準備（イベント前）

### 1.1 フォルダ構成

lucky-draw フォルダには以下が含まれている必要があります。

```
lucky-draw/
├── index.html
├── script.js
├── style.css
├── server.js
├── package.json
├── prize_pics/       … 賞品画像（LD_0001.png 等）
├── sounds/           … SE・ファンファーレ・BGM
│   ├── *.mp3 または *.ogg
│   └── BGM.ogg       … メインBGM（任意）
└── config.json       … あれば（必須ではない）
```

### 1.2 持っていくもの

- **lucky-draw フォルダ全体**を SD カードまたは USB メモリにコピー
- 賞品画像（`prize_pics/`）、音源（`sounds/`）もフォルダ内に入れておく
- Node.js がインストールされた Chromebook（Linux 開発環境）

---

## 2. Chromebook でのセットアップ

### 2.1 Linux 有効化

1. Chromebook の **設定** → **詳細** → **開発者向け**
2. **Linux 開発環境** をオンにする（初回はセットアップが完了するまで待つ）

### 2.2 Node.js のインストール（未導入の場合）

ターミナルを開き、以下を実行します。

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
node -v   # v20.x.x と表示されれば OK
```

### 2.3 lucky-draw フォルダのコピー

1. SD カード／USB を挿入
2. ファイルマネージャーで `lucky-draw` フォルダを **Linux のホーム直下** にコピー  
   例: `/home/ユーザー名/lucky-draw`
3. ターミナルでフォルダに移動：

```bash
cd ~/lucky-draw
```

---

## 3. 起動方法

### 3.1 サーバー起動

```bash
cd ~/lucky-draw
node server.js
```

次のような表示が出れば起動成功です。

```
Server running at http://localhost:8080
```

### 3.2 ブラウザで開く

1. Chrome ブラウザを開く
2. アドレスバーに `http://localhost:8080` と入力して Enter
3. 抽選画面が表示されます

### 3.3 終了

- ターミナルで **Ctrl + C** を押すとサーバーが終了します

---

## 4. 本番前の確認

### 4.1 賞品の読み込み

1. 画面上部の **設定** ボタンをクリック
2. **賞品 一覧** タブを開く
3. **スプシを開く** でスプレッドシートの賞品を確認
4. **更新** を押して賞品データを読み込む
5. 画像は `prize_pics/` フォルダから自動で読み込まれます

### 4.2 音源の確認

- **設定** → **音** タブで、SE・ファンファーレ・BGM が設定されているか確認
- `sounds/` フォルダ内のファイルは相対パスで読み込まれます

### 4.3 その他の設定

- **ブランド名**・**イベント名** を必要に応じて変更
- **残り抽選回数カウンター** を ON にしておくと便利
- **サクサクモード** にすると演出時間が短くなります（100回以上回す場合に推奨）

---

## 5. 運用中の注意点

### 5.1 データの保存場所

- **設定**・**抽選履歴**・**残り回数** は **ブラウザの localStorage** に保存されます
- ブラウザを閉じても、同じ Chromebook・同じブラウザで開けばデータは残ります
- **1台運用** のため、他端末との同期はありません

### 5.2 スプレッドシートの「更新」

- 賞品の在庫をスプレッドシートで変更した場合、**設定 → 賞品 一覧 → 更新** を押すと反映されます
- **スプレッドシートの値が優先** されます（ローカルの在庫は上書きされます）

### 5.3 在庫がなくなったとき

- 画面全体に **「※在庫エラー　係員を呼んでください」** が表示されます
- スプレッドシートで在庫を追加し、**更新** を押すとエラーが解消されます

## 6. トラブルシューティング

| 現象 | 対処 |
|------|------|
| サーバーが起動しない | `node -v` で Node.js が入っているか確認。`cd ~/lucky-draw` でフォルダ内にいるか確認 |
| 画像が表示されない | `prize_pics/` フォルダが lucky-draw 内にあるか確認。ファイル名は LD_0001.png 形式 |
| 音が鳴らない | 画面をクリックしてから操作（ブラウザのオーディオポリシー）。`sounds/` 内にファイルがあるか確認 |
| ページが真っ白 | F12 → Console でエラーを確認。サーバーが起動しているか確認 |
