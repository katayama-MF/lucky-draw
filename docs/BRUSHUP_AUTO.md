# 自動ブラッシュアップ（一晩まわす用）

睡眠中に **テストプレイ → フィードバック解析 → 修正適用 → テストプレイ** を最大100ターン、**確認なしで**自動で回します。

## 使い方

**必ず OS のターミナル（Terminal.app など）で実行してください。**  
（Cursor 内だと Puppeteer/Chrome が起動しない場合があります）

```bash
cd /path/to/lucky-draw
npm run brushup:auto
```

- サーバーが起動していなければ自動で起動します。
- 1ターンごとにストレステストを実行し、結果を解析。
- バグがあれば「修正レジストリ」に従って **1つだけ** 修正を適用し、次のターンへ。
- バグが **0 の状態が連続2ターン** 続いたら終了（成功）。
- 適用できる修正がなくなったら終了。
- 最大 **100ターン** で打ち切り。

## 環境変数

| 変数 | 意味 | 既定 |
|------|------|------|
| `TURNS` | 最大ターン数 | 100 |
| `PLAY_COUNT` | 1ターンあたりのプレイ数 | 50 |

例:

```bash
TURNS=50 PLAY_COUNT=30 npm run brushup:auto
```

## ログ

- ログファイル: `logs/brushup-YYYY-MM-DDTHH-MM-SS.log`
- コンソールにも同じ内容を出します。

## 自動で適用される修正

**なし。** 対症療法的なパラメータ調整は行わない。  
バグ検出時はログに結果を出力し、根本原因を正しいプログラム・アルゴリズムで手動対応する。

## 朝の確認

1. `logs/brushup-*.log` の最後の方を読む（何ターン回ったか、最後の結果）。
2. 必要なら単体でストレステスト: `npm run test:stress:run`
3. バグが残っていれば「検出したバグ一覧」「exception の内訳」を元に手動で修正。

おやすみなさい。
