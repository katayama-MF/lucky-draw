# 標準モード・サクサクモード 仕様と設定

実装（script.js）に基づく現状の一覧。変更時はこのドキュメントとコードの両方を整合させること。

---

## 1. 設定項目（config）

| キー | 説明 | 既定値 | 備考 |
|------|------|--------|------|
| **speedMode** | 速度モード | `'normal'` | `'normal'` または `'fast'`。UIでは「標準」「サクサク」。 |
| **reelStopMin** | ストップ後「あと何マスで止めるか」の最小 | `50` | 抽選で N マス先に止めるときの N の下限。 |
| **reelStopMax** | 同上の最大 | `100` | N の上限。max ≥ min にすること。 |

- 保存・読み込み: `saveToStorage` / 読み込み時に `config.speedMode`, `config.reelStopMin`, `config.reelStopMax` を復元。
- 設定画面: 一般タブで「標準」「サクサク」ボタン、および「止まるマス数」の最小・最大を編集可能。

---

## 2. 標準モード（speedMode === 'normal'）

### 2.1 回転フェーズ（START 〜 STOP 有効化）

| 項目 | 値 | 場所（目安） |
|------|-----|--------------|
| ストップボタン有効になるまでの時間 | 1125 ms | stopEnableMs |
| 加速時間 | 0.525 秒 | ACCEL_SEC |
| リール最大速度（表示・移動の上限） | 60 px/フレーム | REEL_SPEED_MAX, MAX_SPEED |

### 2.2 減速フェーズ（STOP 押下後）

| 項目 | 値 | 場所（目安） |
|------|-----|--------------|
| 減速開始時の速度上限 | 60 | maxSpeedForDecel |
| 減速カーブ | speed ∝ (1 - ratio)^0.6 | exp（ratio = moved/moveTotal） |
| 止まるマス数 N | reelStopMin 〜 reelStopMax（既定 50〜100） | stopSpin 内の N |

### 2.3 パターン演出（runPatternFinale）

| 項目 | 値 | 場所（目安） |
|------|-----|--------------|
| smoothMove の基準時間 | 400 ms | baseDuration |
| Feint の「手前で止まってから進む」待ち | 350 ms | feintWaitMs |
| Pendulum の振動時間 | 900 ms | pendDur |

### 2.4 確定〜当選表示（goToConfirmed 以降）

| 項目 | 値 | 場所（目安） |
|------|-----|--------------|
| 目視時間の下限 | 1800 ms | REEL_VIEWING_MS |
| ランク別 目視時間（当選表示までの遅延） | mega: 2200, super: 2200, big: 1800, normal: 1800 (ms) | showWinnerDelayByRank |
| 実際に使う遅延 | max(REEL_VIEWING_MS, showWinnerDelayByRank[ランク]) | viewingMs → setTimeout(showWinner, viewingMs) |

## 3. サクサクモード（speedMode === 'fast'）

### 3.1 回転フェーズ

| 項目 | 値 | 備考 |
|------|-----|------|
| ストップボタン有効になるまでの時間 | 750 ms | 標準より短い |
| 加速時間 | 0.35 秒 | 標準より短い |
| リール最大速度 | 80 px/フレーム | 標準 60 より速い |

### 3.2 減速フェーズ

| 項目 | 値 | 備考 |
|------|-----|------|
| 減速開始時の速度上限 | 80 | 標準 60 より速い |
| 減速カーブ | speed ∝ (1 - ratio)^0.35 | 標準より前の方で速く落ちる |
| 止まるマス数 N | 同じ（reelStopMin 〜 reelStopMax） | 設定は共通 |

### 3.3 パターン演出

| 項目 | 値 | 備考 |
|------|-----|------|
| smoothMove の基準時間 | 250 ms | 標準 400 より短い |
| Feint の待ち | 200 ms | 標準 350 より短い |
| Pendulum の振動時間 | 600 ms | 標準 900 より短い |

### 3.4 確定〜当選表示

| 項目 | 値 | 備考 |
|------|-----|------|
| 目視時間の下限 | 1200 ms | 標準 1800 より短い |
| ランク別 遅延 | mega: 1500, super: 1500, big: 1200, normal: 1200 (ms) | 標準より短い |

## 5. UI・表示

- ツールバー: 「標準」/「サクサク」トグル。押すと setSpeedMode で切り替え。
- 設定パネル: 「標準」「サクサク」ボタン + speedModeDesc「設定の範囲で停止」/「ストップ後 設定の範囲で停止・演出時間大幅短縮」。
- body クラス: サクサク時は `fast-mode` が付与され、CSS で当選オーバーレイのテンポ短縮などに利用可能。
- 保存時ログ: 「設定を保存しました: 速度モード: 標準」/「サクサク」。

---

## 6. 補足

- **FRAME_MS**: 1000/60（60fps 基準）。速度値は「1フレームあたりの移動ピクセル」として使われる。
- **reelStopMin / reelStopMax**: 標準・サクサクどちらでも同じ設定を使用。ストップ押下時に N がこの範囲で抽選され、「現在センター + N マス先」で止まる。
- 仕様変更時は script.js の該当箇所とこのドキュメントを同時に更新すること。
