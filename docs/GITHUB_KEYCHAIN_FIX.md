# キーチェーンにトークンがあるのに push できないとき

「以前トークンを入れたはずなのに Authentication failed になる」場合は、**キーチェーンに古いパスワードや期限切れトークンが残っている**ことが多いです。一度キーチェーンから削除して、あらためてトークンを入力し直してください。

---

## 手順1：キーチェーンから GitHub の情報を削除する

1. **キーチェーンアクセス** を開く  
   - Spotlight（⌘+スペース）で「キーチェーンアクセス」と入力して起動  
   - または アプリケーション → ユーティリティ → キーチェーンアクセス
2. 左の「**ログイン**」と「**キーチェーン：login**」が選ばれていることを確認
3. 右上の検索欄に **`github`** と入力する
4. 一覧に **github.com** が出てきたら、それを**ダブルクリック**して開く  
   （「インターネットパスワード」の種類で出てくることが多いです）
5. **「アクセスを制御」** や パスワードを表示するための **鍵マーク** などは触らなくてよいです
6. そのウィンドウの下にある **「削除」** をクリック（または 一覧で github.com を選んで右クリック → 削除）
7. 確認が出たら **削除** して、キーチェーンアクセスを閉じる

これで、次に `git push` したときに「ユーザ名とパスワード」の入力が再度求められます。

---

## 手順2：もう一度 push して、トークンを入力する

1. ターミナルで次を実行する  
   ```bash
   cd /Users/kata-mba/Desktop/lucky-draw
   git push origin main
   ```
2. **Username** を聞かれたら → GitHub のユーザー名（例：Katayama-MF）を入力して Enter
3. **Password** を聞かれたら → **Personal Access Token** を貼り付ける  
   - 以前使っていたトークンが **有効期限切れ** の場合は、GitHub で新しいトークンを発行して、その新しいトークンを貼り付ける  
   - 発行：GitHub → Settings → Developer settings → Personal access tokens → Generate new token (classic) → **repo** にチェック
4. 「キーチェーンに保存しますか？」と出たら **保存** を選ぶと、次回以降は入力不要になります

---

## トークンの有効期限について

Personal Access Token には有効期限があります。  
「キーチェーンに保存した」のは「その時点のトークン」なので、**期限切れになったトークン**がキーチェーンに残っていると、毎回それを使ってしまい Authentication failed になります。

- 期限切れの場合は、GitHub で **新しいトークンを発行** し、手順2の Password のところに **新しいトークン** を入力し直してください。
- 新しいトークンで push が成功したら、キーチェーンにはその新しいトークンが保存されます。
