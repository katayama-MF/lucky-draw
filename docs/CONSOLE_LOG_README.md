# コンソールログの見方（賞品読み込み）

「設定 → 賞品一覧 → 更新」のあと、F12 → Console に出るログの意味です。

## 1. 検出列・ヘッダー

```
[賞品読み込み] 形式B 検出列: {colRank: 1, colName: 2, ...} ヘッダー: ['管理No.', '賞品レート', '商品名', ...]
```

- **colRank**: 賞品レートを読む列（0始まり）。**1 = B列**が正しいときが多いです。
- **colName**: 商品名を読む列。**2 = C列**が正しいときが多いです。
- ヘッダーに「賞品レート」が含まれる列を優先して colRank に使うようにしています（別の「レート」列と取り違えないため）。

## 2. 行ごとの読み取り結果

```
[賞品読み込み] 行2: row[colRank]="MegaSuperBigHit" row[colName]="ベルテックス..." → rank=mega
[賞品読み込み] 行3: row[colRank]="SuperBigHit" row[colName]="マグナとふしぎの少女..." → rank=super
```

- **row[colRank]**: その行の「賞品レート」列の**生の値**（スプシのセルそのもの）。
- **→ rank=**: アプリが解釈したレート（mega / super / big / normal）。

**ポイント:**  
アプリは「row[colRank] の値」をそのまま解釈しています。  
「マグナとふしぎの少女 オリジナルグッズ」が SBIG になっている場合、**スプシのその行の賞品レート列に "SuperBigHit" などと入っている**可能性が高いです。メガにしたい場合は、そのセルを「MegaSuperBigHit」や「メガ」に変更してください。

## 3. Invalid string length エラー

読み込み時に「Invalid string length」と出る場合、ログやHTML用に作っている文字列が長すぎてエラーになっています。  
ログ文字列の長さ制限や、列検出の修正で出にくくしてあります。まだ出る場合は、賞品数や画像のデータ量を減らすと改善することがあります。
