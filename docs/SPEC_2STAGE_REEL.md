# 2段階抽選リール 仕様

## 1. 概要

抽選を **2段階** に分ける。

1. **第1段階（レート抽選）**: リールで **レート** を抽選する（MBH / SBH / BH / H の4種類）。ユーザーが **STOP** を押すと、このタイミングで乱数によりレートが決定し、そのマスで止まる。
2. **レート演出**: 止まったレートに応じた演出を入れる。
3. **第2段階（賞品決定）**:
   - **そのレートの賞品が 1 種類だけ**（スプシでそのレートの行が1行だけ）→ **賞品リールは出さない**。その1種類の賞品がそのまま当選。
   - **2 種類以上** → **賞品リールが自動で出現** → **自動で回転開始** → **自動で減速して止まる**。ユーザーは何も押さない。止まった位置の賞品が当選。

**ユーザー操作**: **STOP は 1 回だけ**（レートリールで押す。賞品リールは自動で止まる）。

**抽選の決め方**  
- レート: STOP を押したタイミングで内部乱数で決定。リールはそのマスで止まるようにアニメする。  
- 賞品: 賞品リールが出る場合、自動で減速して止まる前に内部乱数で当選賞品を決定し、そのマスで止まるようにアニメする。

**旧1本リール**: 残さない。2段階抽選のみとする。

---

## 2. レートの定義（現行との対応）

| 表示名 | 内部 rank | 説明 |
|--------|-----------|------|
| **MBH** | `mega` | メガビッグヒット |
| **SBH** | `super` | スーパービッグヒット |
| **BH** | `big` | ビッグヒット |
| **H** | `normal` | ヒット（通常） |

**原則**: **H（normal）は賞品を1種類だけ**セットすること。MEGA / SUPER / BIG は複数種類可、H のみ単品運用を推奨。

賞品データは **スプシの1行＝賞品1種類**。在庫数もその行で管理する。  
各レートごとに「賞品の種類数」＝**そのレートのスプシの行数**。1行だけなら第2リールなし、2行以上なら賞品リールで決定する。

## 3. 画面フロー

### 3.1 第1段階（レート）

- **START** 押下 → 第1段階の **レートリール** が回り始める。
- **STOP** 押下 → **このタイミングで内部乱数により「今回のレート」を決定** → レートリールはそのマスで止まるように減速・停止。
- 止まったマスが「今回のレート」（MBH / SBH / BH / H のいずれか）。

### 3.2 第2段階の要否（賞品の種類数で分岐）

スプシ／賞品設定で、**そのレートに属する賞品が何種類か** を判定する。

- **1 種類だけ**  
  → 賞品リールは **出さない**。その1種類の賞品を当選として **当選表示** へ進む。
- **2 種類以上**  
  → **賞品リール** を表示し、回転開始（下記 3.3）。

### 3.3 第2段階（賞品リールが出る場合）

- 該当レートの賞品だけを並べた **賞品リール** が **自動で出現** し、**自動で回転開始**。
- **自動で減速して止まる**。止まる前に内部乱数で当選賞品を決定し、そのマスで止まるようにアニメする。ユーザーは STOP を押さない。
- 止まった位置の賞品が当選 → **当選表示** へ進む。

---

## 4. リールの種類と表示内容

### 4.1 第1リール（レートリール）

- **表示するマス**: MBH / SBH / BH / H の **4種類**。各レート用の **画像** を用意する。
- **合計 50 枚程度** のマスで、**在庫の割合に合わせてだいたい** 各レートの枚数を配分する。枚数が多いほど当たりやすい見た目になる。
- 4種類の画像が回転するリール。
- **止まり位置**: STOP 押下時に乱数でレートを決め、**そのレートのマスで止まる**ようにアニメする。**止まり方にバリエーション**（オーバーシュートして戻る、など）を入れる。

### 4.2 第2リール（賞品リール）※ 該当レートの賞品が 2 種類以上あるときだけ出現

- **表示位置**: **レートリールとは別の位置** にリールが出現する。画面構成は「レートリール（上）」「賞品リール（下）」の2段とする。
- **表示するマス**: 第1段階で決まったレートの **賞品のみ**（スプシの行。2行以上ある場合）。
- **在庫 0 の賞品**: リールには表示するが、**当選確率は 0** とする（在庫数＝当選の重み）。
- **回転時間**: **標準モード** は約 **7秒** 回してから減速、**サクサクモード** は約 **3秒**。レートで長さは変えない。モード切り替えで変更。
- **止まり方**: バリエーションを入れる（オーバーシュートなど）。
- **止まり位置**: 自動で減速して止まる前に乱数で当選賞品を決め、**その賞品のマスで止まる**ようにアニメする。
- 該当レートの賞品が **1 種類（1行）だけ** のときはこのリールは出さず、その賞品をそのまま当選とする。

## 5. データ・確率

### 5.1 賞品プールと「種類数」（既存スプシを流用）

- **既存のスプシ形式をそのまま使う**。形式A: レート, 賞品名, **本数**, 画像URL。形式B: 管理No., 賞品レート, 商品名, 文字数, **当選個数**, 画像No。
- **スプシの 1 行 ＝ 賞品 1 種類**。在庫数は **本数／当選個数** 列（既存の `count`）で、`prizePool[]` の各要素の `count` として読み込まれる。
- **各レートごとに「賞品の種類数」＝そのレートの行数**。1行だけなら第2リールなし、2行以上なら賞品リールを出す。

### 5.2 確率はすべて「在庫数」で決める

- **スプシの在庫をいじれば、確率は自動で変わる**。別途確率設定は持たない。
- **レート抽選**: 各レートに属する賞品の **在庫数の合計** の割合でレートを抽選する。**在庫が 0 のレートは確率から除外**する（そのレートは出ない）。
- **賞品抽選**: 該当レート内では **在庫数＝当選確率（重み）**。在庫 0 の賞品はリールには出るが当選確率 0。

### 5.2.1 当選後の在庫

- **当選した賞品はアプリ内で在庫を 1 本減らす**。賞品が足りなくならないようにする。次回以降の抽選では減った在庫に応じて確率が自動で変わる。

### 5.3 第1段階：レート抽選（STOP 時に決定）

- **STOP を押した瞬間** に、上記の在庫ベースの重みで **レートを 1 つ決定**。
- 決まったレートのマスでリールが止まるようにアニメする。

### 5.4 第2段階：賞品が 1 種類のとき

- そのレートの賞品が 1 行だけ → 賞品リールは出さず、**その賞品を当選** として当選表示へ。

### 5.5 第2段階：賞品リール（賞品が 2 種類以上のとき）

- 賞品リールが自動で回り、**自動で減速して止まる前** に、在庫数を重みに **当選賞品を 1 本決定**（在庫 0 は重み 0）。
- 決まった賞品のマスでリールが止まるようにアニメする。

## 6. UI の状態遷移

```
[idle]
  → START → [stage1_spinning]  レートリール回転中

[stage1_spinning]
  → STOP（ユーザーはここで1回だけ押す）→ 乱数でレート決定 → [stage1_stopping]  そのマスで止まるアニメ

[stage1_stopping]
  → 止まった → レート演出 → そのレートの賞品「行数」を判定
      ├─ 賞品 1 行だけ → その賞品を当選 → [showing] 当選表示（賞品リールは出さない）
      └─ 賞品 2 行以上 → [stage2_spinning] 賞品リール自動出現・自動回転開始

[stage2_spinning]
  → 自動で減速 → 乱数で当選賞品決定 → [stage2_stopping]  そのマスで止まるアニメ（ユーザー操作なし）

[stage2_stopping]
  → 止まった → [showing] 当選表示

[showing]
  → NEXT → [idle]
```

---

## 7. 画面構成のイメージ

- **レイアウト**: **レートリール** と **賞品リール** は **別の位置**。上にレートリール、下に賞品リールが出る2段構成。「レートリール」「賞品リール」という並び。
- **第1段階**: 上段のレートリールに「MBH / SBH / BH / H」の画像が流れる（合計50枚程度、在庫割合でだいたい枚数配分）。
- **レート演出**: 止まったレートに応じた演出。
- **第2段階（賞品が2行以上）**: **下段（別位置）** に賞品リールが自動で出現し、該当レートの賞品だけが並んで自動で回転・自動で減速して止まる（標準約7秒／サクサク約3秒）。
- **賞品が1行だけ**: 賞品リールは出さず、当選表示へ。
- **H 時**: レートリールは止まったまま「H」表示で、賞品が1行ならそのまま当選表示へ。

---

## 8. 確定済み事項まとめ

- 賞品の種類数 ＝ スプシの1行＝1種類。在庫数もその行で管理。
- ユーザーは STOP 1回だけ（レートリール用）。賞品リールは自動で回って自動で止まる。
- **標準モード**: 賞品リールは約7秒回してから減速。**サクサクモード**: 約3秒。レートで長さは変えない。止まり方にバリエーションあり。
- レートリール50枚の内訳は **在庫の割合に合わせてだいたい** 配分。枚数が多い＝当たりやすい見た目。
- 当選した賞品は **アプリ内で在庫を1本減らす**。次回以降の確率に反映。
- **在庫 0 のレート** はレート抽選の時点で **確率から除外**（出ない）。在庫 0 の賞品はリールには出るが当選確率 0。
- レート・賞品とも確率は在庫数に応じて決める。在庫をいじれば確率も自動で変わる。
- **賞品リールはレートリールと別の位置に出現**。上にレートリール、下に賞品リールの2段構成。
- 旧1本リールは残さない。2段階抽選のみ。

---

## 9. 実装時の分割案

1. **データ**: スプシ取り込みで 1行＝1賞品（在庫数付き）、rank 付与。レート確率＝各レートの在庫合計の割合（**在庫0のレートは除外**）。賞品確率＝在庫数（0なら重み0）。**当選時に在庫を1本減らす**。
2. **モード**: 標準（賞品リール約7秒）／サクサク（約3秒）の切り替え。
3. **第1リール（レートリール）**: 上段に配置。4種類の画像で合計50枚程度、在庫割合でだいたい枚数配分。STOP で乱数→レート決定→そのマスで止まるアニメ。止まり方にバリエーション。
4. **レート演出**: 止まったレートに応じた演出を挿入。
5. **分岐**: 賞品が1行だけ→その賞品を当選して在庫1減→当選表示。2行以上→賞品リールへ。
6. **第2リール（賞品リール）**: **下段・別位置**に出現。該当レートの賞品のみ（在庫0も表示、重み0）。自動で回転開始→モードに応じた時間で自動減速→乱数で当選決定→そのマスで止まるアニメ。止まり方にバリエーション。当選したら在庫1減。
7. **当選表示**: 第1のみで当選した場合と第2で当選した場合の両方で共通の当選表示。
8. **旧1本リール**: 削除。2段階のみとする。
