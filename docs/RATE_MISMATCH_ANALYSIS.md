# スプシとアプリの賞品レート不一致 分析レポート

## 現象
- 「マグナとふしぎの少女 オリジナルグッズ」: スプシではMEGA → アプリではSBIG
- 「Amazonギフト券 5000円」: スプシではMEGA → アプリではBIG

## 想定される原因

### 1. 列インデックスの誤検出
`detectPoolColumns` がスプシのヘッダーから列を検出しますが、次の場合に誤る可能性があります：
- ヘッダー名が想定と異なる（「商品」のみ、「レート」のみなど）
- 列の並び順が想定と異なる（商品名が賞品レートより前など）
- ヘッダーが1行目でない

### 2. parseRank のパターン不足
スプシで「メガ」「スーパー」「ビッグ」など日本語表記を使っている場合、現状の `parseRank` は「メガ」「超」「大」「当」のみ対応。「スーパー」「ビッグ」は未対応で normal に落ちる可能性。

### 3. CSV取得元の不一致
- 「ウェブに公開」のCSVは **特定シートのみ** エクスポート
- 編集しているシートと公開シートが違うと、スプシで見ている内容とCSVが一致しない
- 公開の反映に時間がかかることがある

### 4. fixRankNameSwap の誤作動
レートと商品名の列が逆の場合に交換しますが、`looksLikeRankValue` の判定が曖昧だと不要な交換や未交換が起きる可能性があります。

## 修正方針
1. parseRank に日本語表記（スーパー、ビッグ）を追加
2. detectPoolColumns の列検出パターンを拡張（「商品」単体など）
3. スプシ読み込み時に検出した列とサンプル行をコンソールに出力（デバッグ用）
