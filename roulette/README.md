# マグナお楽しみ抽選システム（マグナ抽選ルーレット）

オンラインイベント（クイズ大会・バトル大会）の最後に、Zoomの画面共有で賞品を抽選するアプリ。
1〜75の賞品番号をリールで回し、STOPで止めて賞品を開示する。

- 2026年8月に Claude Design で作成。2026/10/15 に Claude Design から書き出してこのブランチへ移した。
- リポジトリ直下の旧版（パチスロ風 LUCKY DRAW、Node起動）とは別物。旧版は参照用として保管。
- 仕様：[docs/spec-v3.md](docs/spec-v3.md)

## 動かす場所

- **テスト・本番で動かすのは Claude のアーティファクト「マグナ抽選ルーレット テスト版」**（片山のアカウント。`roulette/` をそのまま公開したもの）。
  - Claude 内の Design（キャンバス）にも置いてあるが、そちらは音が鳴らないため見た目確認用。
  - アーティファクト公開時は `_ds/` を `ds/` に読み替えて載せる（先頭が `_` のフォルダは公開できないため）。
- 正本はこのブランチ。アーティファクトはここから更新する。

## 起動（PCで直接動かす場合）

サーバー不要。`index.html` をChromeで開くだけで動く（ネット接続が必要：React・フォントをCDNから読み込む）。

ローカルでファイルを配信したい場合：

```bash
cd roulette
python3 -m http.server 8080   # → http://localhost:8080
```

当日の手順：
1. 開くと「Zoomで音を届けるには」が出る →「はじめる」
2. Zoomの画面共有で「コンピューターの音声を共有」をON（BGM・効果音の既定音量30%）
3. 抽選 → START → STOP → 賞品を見る → 次へ

## データの保存

- 賞品リスト・抽選結果・設定はブラウザの localStorage（キー `magna-roulette-v3`）に保存される
- 端末・ブラウザごとに別。当日使うPCで準備すること
- 画像を多く登録すると保存容量を超えることがある → 設定画面の「JSON書き出し」でバックアップ、「JSON読み込み」で復元

## 賞品データ

Googleスプレッドシート「クイズ大会賞品リスト」の該当日タブ（例：`20261031`）から取り込む。
賞品リスト画面の「スプレッドシートから取り込む」にシートのURL（タブを開いた状態のURL）を貼って「取り込む」。

- Claude のアーティファクトで開いているとき：Google Sheets 連携（閲覧者本人の権限）で読む。共有設定の変更は不要。初回は連携の許可を求められる
- それ以外の環境：シートが「リンクを知っている全員が閲覧可」のときだけ読める。読めないときは CSV 書き出し／貼り付け

| アプリが想定する列 | シートの実際の列 |
|---|---|
| 番号 | 賞品番号 |
| 賞品名 | 賞品名 |
| レア度 | レート（MEGA / BIG / NORMAL） |
| 補足 | 補足 |
| 全員 | 全員に |
| 使う | （なし） |
| — | 画像ファイル名（LD_0001.png 等、Driveフォルダ） |

列名の読み替え（賞品番号・レート・全員に）は対応済み。

画像は「ここに画像をまとめてドロップ」で入れる。シートの「画像ファイル名」列と一致するファイル名の賞品に割り当てる（列が無いときはファイル名の数字＝賞品番号）。

## ファイル構成

- `index.html` … アプリ本体（Claude Design の `.dc.html` 形式。`support.js` が実行環境）
- `support.js` … Claude Design のランタイム（React を unpkg から読み込む）
- `_ds/` … マグナスクール Design System のトークン・コンポーネント
- `assets/` … ロゴ、BGM、効果音
- `docs/spec-v3.md` … 仕様案 v3
